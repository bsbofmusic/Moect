# Moect 1.3.1

- **批量导出**：按系统负载并行处理，展开任务可查看各会话的进度。所有会话归入同一个目录，开启压缩时只生成一个 ZIP。
- **会话选择**：新增「上一次导出」，可恢复当前账号或本地归档最近一次成功导出的会话勾选。
- **媒体兼容**：会话预览支持直接播放 FLAC，改善早期微信 SILK 语音的导出。新导出的 HTML 简化了视频、骰子和猜拳的显示。
- **缓存与浏览**：修复缓存位置迁移和旧副本清理，减少会话、朋友圈和收藏的重复加载，整理收藏 HTML 布局并修复聊天归档的页码悬停配色。

## 下载与升级

- **安装版**：下载 `Moect-1.3.1-Setup-x64.exe`，运行安装程序即可升级。
- **便携版**：下载 `Moect-1.3.1-Windows-x64.zip`，完整解压后运行 `Moect.exe`。

支持 Windows 10 1809 及以上和 Windows 11（64 位）。

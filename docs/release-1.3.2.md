# Moect 1.3.2

+- 一些 2020 年前后的微信语音现在能正常导出成可播放的音频，收藏里的语音也用上了同一套修复。
- 朋友圈和收藏支持并行处理本地附件，图片、音频和视频较多时导出更快。
- 朋友圈和收藏的 HTML 归档统一成和会话一样的版式。也修复了批量归档标题错位，以及 Excel、CSV、Markdown 导出中的几个兼容问题。
- 导出完成后，点「打开文件位置」会在资源管理器里选中成品。附件有缺失时，鼠标移到任务旁的问号上就能看到原因和处理办法。
- 通知、菜单和常用弹窗换成磨砂玻璃样式，调整了多选、时间范围和压缩加密选项的操作。

## 下载与升级

- 安装版下载 `Moect-1.3.2-Setup-x64.exe`，运行安装程序即可升级。
- 便携版下载 `Moect-1.3.2-Windows-x64.zip`，完整解压后运行 `Moect.exe`。

支持 Windows 10 1809 及以上和 Windows 11（64 位）。
